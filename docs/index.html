工程技能与工作区工具需明确不同职责：mattpocock/skills、garrytan/gstack、google/skills 提供工程或产品指引，max-sixty/worktrunk 管理目录与流程。学习步骤：对一个虚构改动列规格、权限、测试和提交证据，区分指导规则、实际工具能力及平台条件；作者使用经验不是普遍效率证明。

桌面与浏览器动作都要再次观察：vercel-labs/agent-desktop 与 vercel-labs/agent-browser 分别面向原生界面和网页引用。关注信号是把操作目标和结果显式化。验证步骤：用虚构窗口或公开静态页设计跳转、元素失效和遮挡场景的检查清单，不操作真实私密应用，不扩大系统权限。
