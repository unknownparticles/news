Octoverse 回看：代理参与与开发活动增长不能等同质量

GitHub Octoverse 报告称九月超过四成 PR 由可检测代理开始起草，并描述提交、推送与审查工具使用增长。报告明确只描述已观测使用，不是模型质量评价，代理信号也不能覆盖所有使用。本期回看近七日官方统计，不独立重算平台遥测，不把相关性或活动量当作 AI 导致生产率提升的因果证据。
