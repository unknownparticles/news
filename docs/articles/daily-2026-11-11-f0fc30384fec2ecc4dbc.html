Git 发布六项安全修复，内置副本也需核对

GitHub 官方公告称 Git 发布修复六项安全问题的新版本，包括 Git 2.56.1 及多个维护分支补丁版。文章建议同时更新操作系统分发的 Git 与应用内置副本，并区分 GitHub 云服务已部署修复、企业服务可升级版本和部分应用协调推出中的状态。本文不提供利用方法，也未检查本机版本或自动安装更新；不能从云端已修复推断所有桌面和自动化环境已经完成升级。

原文发布：11-11 02:00 北京时间

阅读原文 · GitHub Blog · Git 安全修复公告 ↗

为什么值得关注

同一机器可能运行系统 Git、IDE 内置 Git 和自动化镜像，单个版本号不能覆盖全部执行路径。

下一步

通过各软件官方发行渠道核对实际 Git 路径、修复版本和发布说明；建立清单后按正常维护流程升级，不克隆未知样例验证漏洞。
