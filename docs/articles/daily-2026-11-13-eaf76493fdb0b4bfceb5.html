GitHub 发布十月可用性复盘，扩容与恢复分别检验

GitHub 发布十月可用性报告，记录八起事件及影响、处置和改进，涉及数据库路由、迁移负载、模型提供方认证及网络依赖。报告说明部分事件中同步重连放大了负载，随后限制新连接速率并加入随机延迟；容量扩张与跨区恢复仍需单独验证。本文确认官方发布的复盘，不把历史诊断外推到本次自动化或其他客户端的重连原因，也不把所有标题事件时长等同所有用户持续不可用。
