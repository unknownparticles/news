ThinkingBox 用数据库终态检查训练代理

微软作者发布 ThinkingBox-Training，将执行后的数据库状态与预期结果比较，并把可执行检查用作代理后训练奖励。文章报告 Qwen3.8-27B 经五十步 GRPO 后，在其评测配置中的平均成功率从 51.70% 升至 60.78%；训练任务与基准任务分开。结果属于作者实验，不能推广为任意代理在生产流程中的成功率。

原文发布：10-23 06:24 北京时间

阅读原文 · Microsoft · ThinkingBox 训练研究 ↗

为什么值得关注

有副作用的代理需要核对真实数据变化；对话看似合理、工具调用成功与业务完成是不同指标。

下一步

在可重置的合成订单数据库中定义预期终态，记录漏改、多改与回滚，再考虑训练；不连接真实客户系统。

证据摘录与核验时间 · 1 个
  • Microsoft · ThinkingBox 训练研究 ↗
    We built ThinkingBox to evaluate an agent's work by comparing the final database state with the expected outcome. We then used the same kind of executable signal as a reward on training tasks outside ThinkingBox-Bench. For Qwen3.8-27B, average success rose from 51.70% to 60.78%, while tasks completed correctly on all twenty attempts rose from 38 to 107 with 50 GRPO steps.
