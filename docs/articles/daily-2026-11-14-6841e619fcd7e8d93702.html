llama.cpp 库发布 1.0.0，接口不兼容将升主版本

ggml-org 宣布 llama.cpp 与相关库的 1.0.0 里程碑，表示后续 API 和 ABI 不兼容变化将反映为主版本提升，并介绍分发、持续集成及后端支持工作。本文记录维护者自述的发行与兼容规则，未实际编译、下载模型或逐平台复测；版本稳定承诺不能外推为所有下游应用无须回归、任意模型可运行或本地推理自动满足全部隐私与资源要求。
