GitHub 发布 Copilot 项目上下文指南：分别使用仓库指令、Skills、Agents 与 MCP

GitHub 官方新教程说明如何通过 .github/copilot-instructions.md 写入项目通用约定，通过 .github/skills 封装重复流程、.github/agents 定义专门角色，并用 MCP 连接外部工具。它是配置与使用指南，不代表这些功能均在本日首次推出；也没有证明配置后一定提高成功率。

原文发布：10-13 01:43 北京时间

阅读原文 · GitHub Blog · 官方使用指南 ↗

为什么值得关注

多仓库开发团队可以把测试入口、命名规则和交付要求写成可维护的项目资料，降低新成员与编码助手的上下文缺失。

下一步

选一个测试项目先补充仓库指令与一个质量检查流程，再对照没有这些资料时的任务结果；外部工具只配置必要权限。
