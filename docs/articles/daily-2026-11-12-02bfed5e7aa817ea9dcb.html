Gemini Decisions API 以候选概率支持有界选择

Google 介绍 Gemini Decisions API 与 Gemini Decision 1，用多模态输入对最多一千个独立问题进行有界选择、是非判断或量规评分，返回候选概率与置信度。公告列每百万输入 token 零点一美元、输出 token 不计费，并对部分输入长度和问题数报告延迟实验。本文未实际调用或复测校准，不能把一百至二百五十毫秒外推到所有二十五万六千 token 输入及一千问题组合，也不把概率高当作事实正确或已获执行授权。
