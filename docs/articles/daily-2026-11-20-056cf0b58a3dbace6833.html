Gemini Tool Retrieval 预览按需加载参数，名称描述仍可见

Google 在 Gemini Interactions API 预览 Tool Retrieval：延迟工具的名称与描述仍在上下文中，模型需要时再加载参数 schema；服务器及客户端检索有不同往返方式。功能无独立收费，固定搜索提示和已加载模式仍按普通 token 计费并影响后续对话。本期未调用或复测，不把按需加载等同所有工具开销归零、授权自动满足或任意规模都能节省。
