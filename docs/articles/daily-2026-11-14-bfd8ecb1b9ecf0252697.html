Create Streets 建议小幅街道改造，消费估算待检验

Guardian 介绍 Create Streets 与自行车设施企业共同形成的商业街报告，主张以较小改造改善步行与停留，并对停车、自行车及户外餐饮空间作消费估算。本文未直接读取完整测算模型或独立核查因果效应，明确这些属于报告建议与假设；单地空置率变化不能证明所有改善均由某一改造造成，也不作为安全设施可任意拆除的依据。

为什么值得关注

商业街活力还受交通需求、无障碍、公共安全和商户组合影响，空间估值与已实现营业收入不同。

下一步

先核对报告方法及当地规划规则，用虚构街段列客流、停留、可达性和维护指标，再设计可比较观察；不擅自改变公共设施。
