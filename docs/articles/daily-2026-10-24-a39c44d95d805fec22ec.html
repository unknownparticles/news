Kimi K3.1 Pro 上线，完整权重仍待十一月发布

月之暗面介绍 Kimi K3.1 Pro 与 Highspeed 版本，称支持一百万 token 上下文，已通过 Kimi 产品和 API 提供访问。官网明确完整模型权重将在十一月四日前发布，不能把公告中的 open-weight 定位写成今日已经可以下载完整权重。编程、三维与金融研究表现及速度提升来自机构自述，本期没有独立复测或核实全部计费条款。

原文发布：10-24 00:00 北京时间

为什么值得关注

评估长上下文任务多了一个服务候选，当前 API 可用性、后续权重及许可是不同问题。
