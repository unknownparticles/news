Game Off 公布 SHIFT 主题，提供月度游戏原型练习入口

GitHub 公布 Game Off 2026 主题 SHIFT，邀请围绕主题在一个月内制作游戏，公告列提交截止为十二月一日 13:37 PST。主题允许多种解释，文章展示创意示例并非完整参赛合同。本期未报名或提交，也未据公告确认所有资格、奖项和作品许可，不能包装成确定收入或全国 AI 奖金赛。

独立开发者可用明确主题限制原型范围，把完成度、玩法与可访问性作为学习验收。
