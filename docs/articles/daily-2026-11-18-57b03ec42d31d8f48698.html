Agent Host Protocol 介绍跨设备会话与状态确认

GitHub 工程文章介绍 AHP，以 URI 通道和 reducer 状态对象组织根、会话及聊天能力，宿主协调客户端动作并确认状态。作者说明 VS Code 与 GitHub 使用独立实现，在多客户端接入时发现并修正扩展及假设差异。本期只读架构资料，未独立复测互操作性，不将协议连续性等同所有工具具备幂等、所有客户端兼容或运行宿主永不停止。
