系统与应用内置 Git 的补丁覆盖清单

Git 官方修复公告明确要求同步核对应用内置副本，而云服务和桌面应用的补丁交付状态不同，为构建执行路径与版本证据清单提供公开信号，不证明已存在付费客户需求。

阅读原文 · GitHub · 内置 Git 更新范围 ↗
适合谁
维护开发机、IDE、CI 镜像及代理工具链的开发者与小团队。
第一步
先用虚构路径和版本清单列系统包、IDE、镜像及宿主应用，映射各官方发行说明与更新时间；实际资产核对仅限本人授权范围，本期不读取系统凭据或安装更新。
窗口
近期先完成官方补丁映射与维护计划，无报名或收益承诺。
风险与不确定性
维护分支版本、厂商回补和应用打包可能不同；单看大版本或云端已修复不足以判断全部本地风险，未知仓库和漏洞样例不能用于随意测试。
