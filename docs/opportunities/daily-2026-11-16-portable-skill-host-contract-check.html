技能迁移后的工具、权限与输出证据清单

官方实践指南明确技能可复用但工具、凭据和权限仍属环境，提供跨宿主执行条件与验收证据的检查依据，不保证免审、自动部署或付费需求。

阅读原文 · GitHub · 宿主条件 ↗
适合谁
维护多个编码客户端、团队流程或本地自动化的小团队与开发者。
第一步
用虚构只读报告任务列技能版本、项目清单、参考文件、工具能力及预期输出，人工比较两个假想宿主缺项；不安装第三方技能、不修改权限或登录。
窗口
未来一周先做纸面兼容表与现有公开说明核对，没有官方申请截止。
风险与不确定性
宿主工具与版本会变，发现的仓库惯例不一定应保留；文档承诺不能代替执行证据，静态审查也不等于测试，不能用于绕过授权。
