i18n-inline.nvim：在 Neovim 中检查 Flutter 与 Web 翻译不一致

首次项目发现：仓库创建于十月八日。项目文档称支持 Flutter gen-l10n、i18next、next-intl、vue-i18n 与 gettext，可在编辑器中显示翻译并标注缺失或不一致。要求 Neovim 0.10 及以上；动态拼接的键和部分命名空间布局不在覆盖范围内。MIT 许可证文件可查，未实际运行插件。

为什么值得关注

对使用 Neovim 的多语言应用开发者，可减少代码默认文案与翻译文件不同步的问题；其他编辑器工作流需要自行评估接入成本。

下一步

用一个包含 .arb 或 JSON 翻译的小型测试项目验证缺失键、默认文案和动态键的表现，确认误报率后再考虑纳入检查流程。
